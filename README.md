# FoodieHub — React Single-Page Application

An educational online food ordering SPA built with React, Vite, React Router, `useState`, `useReducer`, props, and localStorage.

## Requirements
- Node.js LTS (includes npm)

## Run locally
1. Extract this folder if it is in a ZIP file.
2. Open the `foodiehub` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the Local URL shown in the terminal (usually http://localhost:5173/).

## Features
- Food search and category filters
- Add to cart, quantity updates and item removal
- Delivery fee and order total calculation
- Demo checkout and order history
- Cart and orders saved in browser localStorage
- Responsive layout

Checkout is simulated. No real payment or backend is connected.
